# PURPOSE.md
## このフレームワークの目的

このフレームワークは、単なる実験管理ツールではありません。

目的は：

> 実験・分析・思考・判断を  
> AIと協調しながら、論文化に収束させること

---

## 解決したい問題

研究現場では、次の問題が頻繁に起きます。

- 実験結果が再現できない
- どの設定で得た結果か分からなくなる
- 仮説と結果の対応が曖昧になる
- AIとの議論が履歴として残らない
- 論文にまとめる段階で構造が崩れる

本フレームワークは、これらを

- Git
- 構造化された実験記録
- 目的（Objective）駆動設計
- AIとの分析履歴保存

によって解決します。

---

## 本質

このフレームワークの本質は：

- 実験を回すことではない
- AIを使うことでもない

> 思考のprovenanceを残すこと

です。

---

## 最終ゴール

- 実験は再現可能
- 分析は追跡可能
- 目的は明確
- 判断は記録されている

その状態を作ることが目的です。
